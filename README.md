# inventory-management-systems

Inventory Management System
A simple inventory management system in Python that lets users add, update, search, display, and delete items for basic stock tracking.

Features
Add new inventory items (ID, name, quantity, price)

View all items

Search item by ID

Edit or update item details

Delete an item

Technologies Used
Python 3.x

Installation
Download or clone this repository.

Make sure Python 3 is installed on your machine.

Running the Project
Run the main script:

text
python inventory.py
Follow the menu prompts to use each feature.

Project Structure
inventory.py: Contains main Inventory class and menu logic.

README.md: Project information and instructions.

Design diagrams: Provided as PNG/PDF (if included).

Report: Project documentation and details.

Testing
Manual testing can be performed by using each menu function and entering sample inventory data.​​
